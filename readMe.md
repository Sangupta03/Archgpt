## What it does

Ask ArchGPT to design YouTube, compare Kafka vs RabbitMQ, quiz you on consistent hashing, or explain CAP theorem — and it gives structured, diagram-backed answers grounded in a curated knowledge base of 22 system design documents.

---

## Features

### Intent-Aware AI Agent
Automatically detects what you're asking and picks the right response format:

| What you type | What happens |
|---|---|
| `"Design Swiggy"` | Full design — Overview, Components, DB choice, Scalability, Trade-offs + diagram |
| `"Instagram vs YouTube"` | Side-by-side comparison table + two architecture diagrams (tabbed) |
| `"What is consistent hashing"` | Conceptual explanation with analogy + real-world example |
| `"Quiz me on Kafka"` | 5 MCQs with instant feedback and explanations |

### RAG Pipeline
- 22 curated `.txt` docs: YouTube, Netflix, Uber, Swiggy, Zomato, Instagram, Discord, Dropbox, Twitter, Kafka, CAP theorem, database sharding, microservices, CDN, SQL vs NoSQL + more
- ChromaDB with **gemini-embedding-001** (3072-dim, cosine similarity) — retrieves top-3 relevant chunks per query
- Source chips shown under each AI response so you know which docs were used

### Live Architecture Diagrams
- Mermaid.js diagram auto-generated for every system design
- Multi-tab view for comparisons (e.g. "Myntra vs YouTube" → two tabs)
- Zoom controls, SVG download, dark/light theme sync

### Quiz Mode
- Modal with topic input and quick-select chips
- 5 MCQs generated by Gemini, grounded in ChromaDB context
- One question at a time — A/B/C/D buttons, green/red feedback, explanation after each answer
- Score screen at the end

### Flashcard Mode
- 8 cards per topic (mix of concept, trade-off, example, why)
- CSS 3D flip animation on click to reveal the answer
- Mark each card "Got it ✓" or "Still learning ✗"
- Automatically offers to review only the missed cards

### Other
- **SSE streaming** — answers appear token by token, no waiting
- **Dark / light theme** toggle, persisted across sessions
- **Google OAuth + JWT** auth — sign in to save sessions
- **Session history** — save and reload past conversations
- **Thumbs up/down feedback** on every AI response (stored in DB)
- **Model selector** — switch between Gemini Flash Lite and Flash
- **Export PDF** — print the chat via browser print dialog
- **Resizable panels** — drag the divider between chat and diagram

## Tech Stack

| Layer | Tech |
|---|---|
| Frontend | React 18, Vite, CSS custom properties (dark/light theme) |
| Backend | Python, FastAPI, SSE streaming |
| AI | Google Gemini 2.5 Flash (chat, quiz, flashcards) |
| Embeddings | gemini-embedding-001 (3072-dim vectors) |

## Running Locally

### Backend

```bash
cd backend
python -m venv venv
.\venv\Scripts\activate       # Windows
# source venv/bin/activate    # Mac/Linux

pip install -r requirements.txt
```

Create `backend/.env`:
```
GEMINI_API_KEY=your_key_here
DATABASE_URL=your_postgres_url
GOOGLE_CLIENT_ID=your_client_id
GOOGLE_CLIENT_SECRET=your_client_secret
FRONTEND_URL=http://localhost:5173
REDIRECT_URI=http://localhost:8000/auth/callback
```

```bash
python ingest.py              # embed docs into ChromaDB (run once)
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
# create frontend/.env with: VITE_API_URL=http://localhost:8000
npm run dev
```
